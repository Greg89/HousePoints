Released 2026-07-24

Manage Workspaces and Safer Operations

This release reorganizes administration into focused Manage workspaces, makes common point and member operations clearer, and adds stronger API safeguards and release-readiness coverage.

Highlights

  • Redesigned Manage into focused Overview, Members, Houses, Seasons, Organization, and Audit workspaces.
  • Added deep links, browser history support, responsive navigation, and clearer owner-only permissions throughout Manage.
  • Improved member search, filtering, house assignment, profile editing, role management, and access removal.
  • Added clearer house, season, organization, audit, and point-adjustment management views.
  • Added API rate limiting with stricter safeguards for sensitive write operations.

What's New

  • The Manage overview now calls out unassigned members, missing or empty houses, organization status, and recent administrative activity.
  • Members can be searched and filtered by assignment or role before opening a focused detail panel.
  • House, season, ownership, organization lifecycle, and other consequential changes now use more consistent detail and confirmation surfaces.
  • Point-adjustment reporting can be reviewed by season and house.
  • The Award Points dialog now explains every unmet requirement and shows specific inline validation feedback.
  • Activity cards emphasize the recognized member and clearly identify who awarded or deducted the points.

Fixes

  • Informational notifications for invitations, role changes, seasons, points, reactions, and releases now leave the tray after being read.
  • The notification tray scrolls more reliably on smaller screens.
  • Sign-in navigation handles missing destinations and cross-origin redirects more safely.
  • Manage navigation, search controls, dialogs, and account controls include improved accessibility labels and descriptions.
  • Dashboard loading and error handling are more resilient during navigation.

Operations Notes

  • Run the release notes workflow with this page as releases/2026-07-24-manage-workspaces-safer-operations.html.
  • Use release version 2026.07.24 when recording and broadcasting this release.
  • Record the release first, verify the production deployment and core workflows, then broadcast to users.
  • No database migration or new production environment variable is required for this release.
  • API rate limits use an in-memory store and apply independently to each running API replica.
  • Confirm APP_RELEASE_NOTES_URL, RELEASE_AUTOMATION_SECRET, and RELEASE_RECORD_API_BASE_URL remain configured for release communication.

Verification

  • Verify member, admin, and owner Manage permissions and all six workspace destinations.
  • Verify awarding points, member search and filtering, house assignment, and season reporting.
  • Verify an informational notification disappears from the tray after being read.
  • Verify production API health and confirm ordinary traffic is not unexpectedly rate limited.
  • After recording and broadcasting, confirm the API logs include releases.recorded and releases.broadcasted.
