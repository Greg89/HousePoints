Released 2026-07-05

Multi-Organization Support and In-App Notifications

HousePoints now supports users belonging to more than one organization, with clearer organization switching, account settings, durable in-app notifications, and release announcements.

Highlights

  • Added multi-organization support for users who belong to more than one organization.
  • Added organization switching from the account menu.
  • Added account settings with a dedicated organization area.
  • Added durable in-app notifications in the account menu.
  • Added release announcement notifications for future product updates.
  • Added a persistent What's New link to the public release notes.

What's New

  • Dashboard data, notifications, houses, members, points, and reports now follow the selected organization.
  • Users can create another organization from their account settings.
  • The account menu now keeps organization switching, notifications, release notes, account settings, and sign out in one place.
  • The account menu now behaves better on smaller screens by keeping footer actions reachable.

Operations Notes

  • Release notes are published through GitHub Pages from the committed site directory.
  • Release announcements are recorded in the app before notifications are broadcast.
  • In-app release notifications should be broadcast only after production health is verified.
  • The production web app uses APP_RELEASE_NOTES_URL for the persistent What's New link.
  • The production API and GitHub Actions share RELEASE_AUTOMATION_SECRET for release record and broadcast automation.

Verification

  • CI validation passed.
  • Production deployment completed.
  • Multi-organization switching tested in production.
  • Account menu notifications tested in production.
  • Release notes publishing and release-record automation tested through GitHub Actions.
