Released 2026-07-18

Activity, Reactions, and Notification Cleanup

This release makes the Activity page more useful as the team hub for recognition, adds reactions to point awards, and cleans up point notifications after they are read.

Highlights

  • Refactored the Activity page into a clearer team activity hub with improved recognition cards.
  • Added reactions so teammates can respond to point awards without creating notification spam.
  • Added reaction details so users can see who reacted and when.
  • Improved Activity filters for type, giver, recognized member, and season.
  • Fixed point-award notifications so they archive after the recipient reads them.

What's New

  • The Activity page is easier to scan, with award details, points, season context, and actions arranged more intentionally.
  • Members can react to recognition with a small set of lightweight reactions.
  • Users can change their selected reaction without sending repeated notifications.
  • Admins and owners can still access point actions from the activity card actions menu.
  • Activity history can now be narrowed by recognition vs deductions, who gave points, who received points, and season.

Fixes

  • Point-award notifications now behave like other read-once notifications and leave the notification tray after being read.
  • Reaction selection closes the picker after a reaction is saved.
  • Reaction detail views support longer reaction lists without expanding beyond the screen.

Operations Notes

  • Run the release notes workflow with this page as releases/2026-07-18-activity-reactions-notifications.html.
  • Record the release first, verify production health and notification behavior, then broadcast to users.
  • No new Railway environment variables are required for this release beyond the existing release automation configuration.
  • Confirm APP_RELEASE_NOTES_URL remains configured on the production web app so users can reopen What's New later.
