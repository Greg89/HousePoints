Recognition Integrity Fixes

Point awards and recognition rankings now consistently reflect eligible, active organization members.

Highlights

  • Members can no longer award points to themselves.
  • Removed members no longer leave empty or skipped positions in recognition views.

Fixes

  • The signed-in member is excluded from the Award Points recipient picker.
  • The API rejects direct self-award attempts before creating a point transaction.
  • Season standout selection now considers active organization members only.
  • Leaderboard ranks are assigned after removed members are filtered out, keeping podium positions continuous.

Operations Notes

  • No database migration, environment variable, or feature flag changes are required.
  • Both fixes were verified in the development environment.
  • Automated API tests, typechecks, lint checks, targeted web tests, and the production build pass.
