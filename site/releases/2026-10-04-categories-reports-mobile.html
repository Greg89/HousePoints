2026.10.04

Recognition Categories, Detailed Reports, and Mobile Progress

Customize recognition with organization-owned categories, explore the transactions behind house scores, and catch up on recent mobile improvements.

Recognition That Fits Your Organization

  • Owners can add recognition categories with a name and optional description from Manage > Recognition.
  • Members choose from active categories when awarding points, while admins can inspect category settings without changing them.
  • Archive categories to remove them from future awards without changing scores or losing the labels on past awards.
  • Existing recognition labels carry forward as starting categories. Creating a new category with an archived name keeps its history separate from the original.
  • Activity and recognition summaries retain the category associated with each award, including archived categories.

See the Transactions Behind the Score

  • Open the new Full report link on a dashboard house card to explore its contributing transactions.
  • Review the current or a historical season, drill into a house or recipient, and narrow the ledger by category, giver, or awards versus deductions.
  • Filtered totals sit alongside the full-season totals for the selected house/member scope, making subtotals easier to understand.
  • Load more transactions without losing the selected filters, or share a filtered report link with someone who has access to the organization.

Fixes and Polish

  • Changing report filters now replaces the previous transaction list, totals, pagination, and error state instead of leaving stale results visible.
  • Choosing Deductions only for a house with no deductions shows an empty ledger and zero filtered totals. Switching back to All restores the award results.
  • The category award picker refreshes once when opened rather than repeatedly when the recipient changes, and category-loading failures are surfaced explicitly.

Recent Mobile Progress

Recent committed work prepares the next mobile update. Availability depends on the installed build and the mobile release rollout; this announcement does not mean a new version is already available in app stores.

  • Category-aware award selection and activity let updated mobile clients use the same recognition categories as the web app.
  • Award-form input validation, point controls, scrolling, and keyboard handling have been improved.
  • Retry protection for awards and deductions reduces duplicate submissions when a response is uncertain and the same submission is retried within the open form.
  • Notification navigation now targets the notification's organization, including when another organization is selected or the app needs to finish signing in.
  • Score attribution and tied rankings are aligned across reporting views.
  • The mobile release candidate is now 1.0.2, with Expo compatibility updates and expanded Android checks for award input and category flows.

Operations Notes

  • RECOGNITION_CATEGORY_MUTATIONS_ENABLED (API): enables category creation, archival, and category-based awards.
  • RECOGNITION_CATEGORIES_WEB_ENABLED (web): enables category management and award selection.
  • EXPO_PUBLIC_RECOGNITION_CATEGORIES_ENABLED (mobile): enables category award selection.
  • REPORTS_DRILL_THROUGH_WEB_ENABLED (web): enables detailed report pages and dashboard links.
  • POST /users/bootstrap currently allows 30 requests per minute per authenticated user, per API replica. The limit may be relaxed in a future update if normal navigation and report use show it is too restrictive; this release does not change it.
