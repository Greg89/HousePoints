# Google Play Store Assets

Assets in this directory are prepared for the default Google Play store listing.

- `play-store-icon.png`: 512 x 512 Play listing icon derived from the shipped app icon.
- `feature-graphic.png`: 1024 x 500 promotional feature graphic.

Phone and tablet screenshots must be captured from the real submitted Android build using non-sensitive demo data. Do not substitute generated UI mockups for product screenshots.
